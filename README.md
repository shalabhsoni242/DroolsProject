# Drools-Based Loan Eligibility Checker 🚀

This is my first project leveraging **Drools**, a powerful open-source Business Rule Management System (BRMS). It demonstrates how to build a rule engine to automate loan eligibility decisions based on various applicant and credit criteria.

## Project Overview 💡

The **Loan Eligibility Checker** is a simple yet effective application that takes in data about a loan applicant and their credit history, then applies a set of predefined business rules to determine if they are eligible for a loan, if a co-signer is required, or why they might be rejected.

This project showcases the core capabilities of Drools, including:
* **Fact Modeling**: Representing business data as Plain Old Java Objects (POJOs).
* **DRL (Drools Rule Language)**: Defining business rules in a declarative, human-readable format.
* **Rule Execution**: Firing rules against inserted facts to derive conclusions.
* **Rule Chaining**: How rules modify facts, leading to other rules being evaluated and potentially fired.
* **Preventing Infinite Loops**: Implementing conditions to ensure rules fire only when necessary.

## Key Technologies Used 🛠️

* **Java 8+**: The programming language for the application.
* **Apache Maven**: For project management and dependency handling.
* **Drools (KIE)**: The core rule engine library.

## Business Rules Implemented ✅

The `loan-eligibility-rules.drl` file contains the following rules:

1.  **"Reject Loan - Low Credit Score"**: Rejects a loan if the applicant's credit score is below 600.
2.  **"Reject Loan - Income vs Debt"**: Rejects a loan if the annual income is less than $30,000 AND existing debt exceeds $10,000.
3.  **"Require Co-signer - Short Employment"**: Requires a co-signer if the applicant has been employed for less than 1 year and is currently employed.
4.  **"Approve Loan - Default"**: Approves the loan if none of the rejection or co-signer rules have been triggered.

## How to Run the Project 🏃

To run this project on your local machine:

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/shalabhsoni242/DroolsProject/Drools-Based Loan Eligibility Checker.git]
    cd loan-eligibility
    ```
2.  **Build the Project:**
    Use Maven to clean and build the project. This will compile the Java code and the Drools DRL rules.
    ```bash
    mvn clean install
    ```
3.  **Run the Application:**
    Execute the main application class.
    ```bash
    mvn exec:java -Dexec.mainClass="com.example.loan.LoanEligibilityApp"
    ```

## My Learning Journey and Challenges 🧠

Building this project helped me grasp fundamental Drools concepts, especially how facts interact with rules and the flow of the rule engine. A key learning curve was understanding how to prevent rules from entering an infinite loop by carefully structuring `when` conditions and ensuring `modify` actions properly change the state to prevent re-firing. This experience has deepened my appreciation for declarative programming and the power of rule engines in managing complex business logic.
